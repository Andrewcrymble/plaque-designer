PLAQUE DESIGNER — iPad Web App

UPLOAD THESE FOUR FILES TO THE SAME WEB FOLDER:
- index.html
- manifest.webmanifest
- service-worker.js
- icon.svg

IMPORTANT:
The website must use HTTPS for the install/offline features to work.

ON IPAD:
1. Visit the hosted index.html/page in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Tap Add.
5. Open Plaque Designer from the new Home Screen icon.

The app itself remains self-contained. Imported customer artwork/images stay in the browser while you work and the finished SVG is downloaded from the device.
