⬇ Laser-ready side-by-side export

Defaults: Main wording 40, small wording 40, verse Courier 10 at Y 133. Verse is red in the design preview; in the laser export it is converted to a high-resolution BLACK engraving image so Falcon reliably imports it.
LEFT PART — BACK PLATE
• Selected outside shape = CUT
• Optional hanging tag + hole on BACK plate = CUT
• Reference / verse = ENGRAVE
• Background image = ENGRAVE

RIGHT PART — FRONT RING + WORDING
• Matching selected outer shape = CUT
• Hole in hanging tab = CUT
• Matching inset opening = CUT
• Main wording = CUT
• Small wording = CUT

Both physical parts are positioned side by side in the same SVG. The downloaded filename is automatically taken from the Main wording.

Laser colour rule: RED = CUT   |   BLACK = ENGRAVE.
Default operation settings: Cut 350 mm/min @ 100%; Image engrave 8000 mm/min @ 80%; Line/reference engrave 3500 mm/min @ 40%.
Download tip: Chrome may ask permission for multiple downloads if you press several export buttons. Each button should download one SVG immediately.
